# Recomendation system of Christmas movies
Проект с рекомендациями фильмов и метриками похожести.

## Навигация по проекту

- `main.py` — основной скрипт проекта.
- `levenshtein.py` — функции расчета расстояния Левенштейна.
- `synthetic-creation.py` — генерация синтетических данных.
- `christmas_movies.csv` — исходный датасет фильмов.
- `christmas_movies_clean.csv` — очищенный датасет.

## Быстрый старт

```bash
python main.py
```
## Как работает система рекомендаций

В основе проекта лежит **гибридная контентная модель** (Content-Based Filtering). Она вычисляет степень похожести двух фильмов, объединяя числовые параметры и текстовые признаки (жанры и актеров).

### Метрики сходства

1. **Сходство Жаккара (`jaccard_similarity`)** — используется для сравнения жанров и актеров. 
   Вычисляет отношение количества общих элементов к общему числу уникальных элементов в двух списках. Возвращает значение от `0.0` (нет общих элементов) до `1.0` (полное совпадение).

2. **Числовое сходство (`numeric_similarity`)** — сравнивает нормализованный рейтинг (`rating_norm`) и длительность (`runtime_norm`) фильмов. 
   Сначала вычисляется **евклидово расстояние** между фильмами в двумерном пространстве. Затем оно инвертируется так, чтобы `1.0` означало полное совпадение, а `0.0` — максимальное различие

### Итоговая формула (`combined_similarity`)

Общая похожесть фильмов рассчитывается как взвешенная сумма трех метрик:

| Признак                  | Вес              | Метод                |
| :----------------------- | :--------------- | :------------------- |
| Рейтинг и длительность   | **40%** (`0.4`)  | Евклидово расстояние |
| Жанры                    | **30%** (`0.3`)  | Сходство Жаккара     |
| Актеры                   | **30%** (`0.3`)  | Сходство Жаккара     |

Итоговое значение всегда находится в диапазоне от `0.0` до `1.0`, где `1.0` — это максимально похожие фильмы.
